# 流程设计器

> 可视化设计业务流程，支持审批、自动化和子流程

## 它能做什么？

**可视化流程设计** — 拖拽节点，连线编排：
- 审批流程（请假、报销、采购...）
- 业务流程（订单处理、客户服务...）
- 自动化流程（数据同步、定时任务...）

**丰富节点类型** — 25 种标准 BPMN 节点：
- 任务节点：用户任务、服务任务、脚本任务
- 网关节点：排他网关、并行网关、包含网关
- 事件节点：开始、结束、定时、消息
- 子流程：内嵌子流程、调用活动

**完整审批能力** — 企业级审批功能：
- 通过 / 驳回 / 委派 / 转办 / 催办 / 撤回
- 加签 / 减签（动态调整审批人）
- 批量审批
- 审批评论
- 超时自动处理

## 快速开始

### 1. 启动服务

```bash
cd flow
pnpm install
pnpm dev
```

### 2. 打开浏览器

访问 `http://localhost:5200`

### 3. 创建你的第一个流程

1. 点击「新建流程」
2. 从左侧节点面板拖拽节点到画布
3. 连接节点，定义流程走向
4. 点击节点，配置属性（审批人、表单、条件...）
5. 保存并发布流程

## 核心功能

### 可视化设计器

- **拖拽编排** — 从节点面板拖拽到画布
- **自动布局** — dagre 算法自动排列节点
- **缩放/小地图** — 大型流程也能轻松编辑
- **复制/粘贴** — 快速复制节点和配置
- **流程导出** — 导出为图片或 JSON
- **流程校验** — 自动检查流程完整性

### 25 种节点类型

**任务节点**
- 用户任务 — 人工处理（审批、填写）
- 服务任务 — 调用外部服务
- 脚本任务 — 执行脚本逻辑
- 发送任务 — 发送消息/通知
- 接收任务 — 等待消息

**网关节点**
- 排他网关 — 单一路径（if-else）
- 并行网关 — 同时执行多条路径
- 包含网关 — 条件满足的路径都执行
- 事件网关 — 基于事件选择路径

**事件节点**
- 开始事件 — 流程启动
- 结束事件 — 流程结束
- 定时事件 — 定时触发
- 消息事件 — 消息触发
- 错误事件 — 错误处理
- 信号事件 — 信号触发

**子流程**
- 内嵌子流程 — 包含在主流程中
- 调用活动 — 调用外部流程定义

### 审批功能

**基础审批操作**
- 通过 — 审批通过，流转到下一节点
- 驳回 — 驳回到指定节点
- 委派 — 委托他人处理
- 转办 — 转交给其他人
- 催办 — 催促审批人处理
- 撤回 — 撤回已提交的流程

**高级审批功能**
- 加签/减签 — 动态调整审批人
- 批量审批 — 批量通过/驳回
- 审批评论 — 添加审批意见
- 审批日志 — 查看完整审批历史
- 超时处理 — 超时自动通过/转交/通知

**审批人规则**
- 指定用户
- 指定角色
- 表达式动态计算
- 排除发起人
- 自动跳过

### 子流程引擎

**内嵌子流程**
- 将复杂流程拆分为子流程
- 支持输入/输出变量映射
- 子流程完成后继续主流程

**调用活动**
- 调用其他已发布的流程
- 分页选择目标流程
- 父子流程实例关联

### 流程管理

- **流程定义** — 创建、编辑、删除、发布流程
- **流程实例** — 查看运行中的流程实例
- **流程监控** — 实时监控流程状态
- **流程统计** — 流程运行数据统计
- **流程模板** — 保存常用流程为模板

### 任务收件箱

- **待办任务** — 需要我处理的任务
- **已办任务** — 我已处理的任务
- **批量操作** — 批量通过/驳回
- **实时通知** — 新任务即时提醒

## 使用场景

### 场景 1：请假审批流程

```
开始 → 员工填写请假单 → 部门经理审批 → [金额判断]
  ├─ ≤3天 → 结束
  └─ >3天 → 总监审批 → 结束
```

### 场景 2：采购审批流程

```
开始 → 提交采购申请 → 部门经理审批 → 采购部审核 → [金额判断]
  ├─ ≤5000 → 财务审批 → 结束
  └─ >5000 → 总经理审批 → 财务审批 → 结束
```

### 场景 3：订单处理流程

```
开始 → 接收订单 → 库存检查 → [库存判断]
  ├─ 有库存 → 发货 → 结束
  └─ 无库存 → 采购流程（子流程）→ 发货 → 结束
```

### 场景 4：客户服务流程

```
开始 → 客户提交工单 → 自动分类 → [类型判断]
  ├─ 技术问题 → 技术支持处理 → 客户确认 → 结束
  ├─ 退款问题 → 财务审核 → 退款处理 → 结束
  └─ 投诉问题 → 客服主管处理 → 客户回访 → 结束
```

## 常见问题

**Q: 如何设置审批人？**
A: 点击用户任务节点，在属性面板中配置审批人：指定用户、指定角色或使用表达式动态计算。

**Q: 流程可以驳回到任意节点吗？**
A: 可以，在驳回对话框中选择目标节点。

**Q: 子流程和调用活动有什么区别？**
A: 内嵌子流程包含在主流程中，调用活动调用外部已发布的流程定义。

**Q: 如何处理超时？**
A: 在节点属性中配置超时时间和超时动作（通知、自动通过、自动转交）。

**Q: 支持并行审批吗？**
A: 支持，使用并行网关实现多条路径同时执行。
